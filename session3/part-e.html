TeX and tikz

Session 3 · Part E

The RITS consultation slides are made from a text file. LaTeX lays out the presentation, and TikZ draws the diagrams. In this activity, you will compile the supplied source on your computer, inspect the resulting slides, and host the PDF on GitHub Pages.

Download the deck and source

  • Open the hosted RITS consultation deck.
  • Download the complete source ZIP — start here to compile the deck. It includes the TeX file, fonts, figures, and a reference PDF.
  • Download the TeX file on its own.
  • Open the reference PDF.

The source is called rits-consultation-deck.tex; the supplied reference PDF is called RITS_Consultation.pdf. The TeX file needs the fonts and figures folders beside it, so download and extract the whole ZIP before compiling.

Install TeX on your computer

Choose the instructions for your operating system. These installations provide the tools that turn a .tex file into a PDF.

Computer What to install
Mac Install the full MacTeX distribution. It includes TeXShop, an editor with a PDF preview.
Windows Install MiKTeX. Allow it to install missing packages when prompted. It includes the TeXworks editor.
Linux Install TeX Live using the full installation. You can compile from a terminal using the command below.

Allow time for the installation and its downloads. The deck’s fonts are already included in the ZIP; keep them in the supplied folder.

Compile and view the slides

  1. Extract rits-consultation-source.zip and open the resulting rits-consultation folder.
  2. Open rits-consultation-deck.tex in TeXShop on Mac or TeXworks on Windows.
  3. In the editor’s typesetting menu, select XeLaTeX. This deck uses fonts that need that compiler; the usual pdfLaTeX setting will give a font error.
  4. Click Typeset. On Windows, accept MiKTeX’s requests to install any missing packages. Run Typeset a second time after the first run finishes so that references and navigation information are updated.
  5. Open rits-consultation-deck.pdf in the same folder. You should see the 77-slide deck. Compare it with the supplied reference PDF.

If you prefer a terminal, open one in the extracted folder and run these commands, waiting for each to finish:

xelatex -halt-on-error rits-consultation-deck.tex
xelatex -halt-on-error rits-consultation-deck.tex

If a font or image cannot be found, check that the ZIP is fully extracted and that fonts and figures are still beside the TeX file. If the terminal does not recognise xelatex, reopen it after installation or use the editor above.

Find a diagram in the source

Choose a slide in the PDF and search for its title in the TeX file. For example, search for DvP/PvP lock and release. A Beamer frame describes a slide; a tikzpicture contains drawing instructions. Within a diagram, \node places text or a shape, and \draw draws lines or connections.

Look back and forth between the source and the PDF. Identify the instructions for one label, one shape, and one connection. This is a way to begin reading a large source file without having to understand every command at once.

Explore the related visualisation

Open www.rtgs.cash, the related RITS visualisation. It shows the RITS settlement engine and the Fast Settlement Service (FSS). Compare how the website and the slide deck represent the same subject: what is easier to understand from the diagram, and what needs the slides’ explanation?

Host your PDF on GitHub Pages

GitHub stores the files; GitHub Pages gives you a website address that other people can open. Use the PDF you just compiled for this exercise.

  1. Sign in to GitHub and create a public repository called tex-slides. Turn on Add README when creating it.
  2. In that repository, choose Add file → Upload files. Upload rits-consultation-deck.pdf to the top level of the repository and commit the upload.
  3. Choose Add file → Create new file, name it index.html, and paste the following page. Commit the file.
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>RITS consultation deck</title>
</head>
<body>
  <h1>RITS consultation deck</h1>
  <p>Compiled from the source supplied for Session 3.</p>
  <p><a href="rits-consultation-deck.pdf">Open the PDF slides</a></p>
</body>
</html>
  1. Open Settings → Pages. Under Build and deployment, set Source to Deploy from a branch. Select main and /(root), then save.
  2. Wait for GitHub Pages to finish publishing. The Pages settings will show the website address, normally https://YOUR-USERNAME.github.io/tex-slides/.
  3. Open that address and click Open the PDF slides. Copy the address of the PDF, then test it in a private browser window.

For help, use GitHub’s official guides to creating a Pages site and choosing its publishing source.
